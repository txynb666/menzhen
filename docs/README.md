# 门诊预约与分诊协作数智化方案

本目录是“门诊预约与分诊协作”项目的交付物索引。方案基于 FDE Discovery Lab 生成的合成场景业务报告，围绕等待口径、队列次序解释、排班同步、交接确认和审计权限展开。所有内容均为待验证方案，不是真实医疗机构的验收结论。

## 方案基线

- 试点范围：两个常规门诊诊区，先做历史回放，再做小范围并行试点。
- 改善目标：候诊中位数由 68 分钟降至 40 分钟，爽约率由 19% 降至 10%，等待时间至少下降 20%，最终以书面冻结口径为准。
- AI 边界：只读排班和队列，只生成解释草稿、异常提示、字段校验建议和摘要；不自动分诊、不诊断、不改医嘱、不重排队列、不替代签核。
- 人工闸门：急症提示、迟到与现场加号、排班通知、交接接收和规则发布必须由授权人员确认。
- 审计要求：保留业务编号、来源版本、证据引用、建议、人工改动和签核人。
- 首期预算：人民币 160,000 元（含税），覆盖诊断、集成、试点、培训、验证与项目管理。
- 可选运维：人民币 8,000 元/月起，最终价格按监控范围、支持时段和服务级别复核。

## 使用说明

PNG 流程图可直接用于汇报；Mermaid 文件可在支持 Mermaid 的 Markdown、GitHub 或文档平台中重新渲染。Word 文档用于行业分析与方案评审，Excel 报价单中的金额和合计使用公式计算，可调整明细后复核总价。

## 重要说明

本项目基于合成场景数据，角色、业务量和指标均用于方案演练。等待时间统计口径、交接记录完整度、反馈入口、排班同步延迟、授权范围和留存期限仍待组织确认。报价与实施周期也需在范围澄清和技术复核后形成正式合同附件。
